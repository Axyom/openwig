# openwig has moved

The openwig Python SDK ended at version **0.1.3**. openwig is now a set of Patchbay mods
for Bitwig Studio: a bridge with an MCP server (`http://127.0.0.1:7779/mcp`) and an agent
panel inside Bitwig. It is no longer a Python package.

- New openwig: https://github.com/Axyom/openwig
- Old Python SDK: `pip install "openwig==0.1.3"` (source at git tag `python-sdk-final`)

This release (0.2.0) only raises an ImportError that points here.
